# ADR-002: единая сцена Landsat для NDVI и LST
Дата 22.11.2026 · статус: предложено, требуется согласование заказчика.
Контекст: ЛР1 предполагала Sentinel-2 для NDVI и Landsat для LST; разные даты создают риск некорректного сравнения.
Решение для первичного анализа: Landsat9 C2 L2 08.07.2025, SR_B4/B5 и ST_B10 одного item, единая QA-маска; Sentinel оставить резервом высокой детализации. Альтернативы: разные спутники (10 м NDVI, но разновременность); Landsat только (согласованность, ниже детализация); многодатный композит (устойчивость, больше работы).
Последствия: NDVI на сетке30м, тепловое исходное разрешение100м, не считать температурные пиксели30м независимыми. Один день не характеризует климат. Порог NDVI0.3/P75LST — правило поиска, а не агрономический стандарт. Не прогнозировать эффект посадок без отдельного исследования.
Проверка: test_ndvi.py, data-quality.md, provenance/scene.json. Решение пока не меняет одобренный scope автоматически.
